## Load maps on demand with ECharts

```ts
import { setLocale } from '@idux/geo-areas/locale'
import { hasGeoJSON, loadGeoJSON } from '@idux/geo-areas/geojson'
import { registerMap } from 'echarts/core'

setLocale('en')
const id: string = 'CN-provinces'
if (hasGeoJSON(id)) {
  const map = await loadGeoJSON(id)
  registerMap('china', map)
}
```

Install ECharts separately and register the chart types, components and renderer you need. This package provides data and does not include chart instances.

### Match business data by code

ECharts matches features by name by default. Set `nameProperty: 'code'` so language changes do not affect data associations:

```ts
const series = {
  type: 'map',
  map: 'china',
  nameProperty: 'code',
  data: [{ name: '370000', value: 100 }],
}
```

When using a `geo` base map, also set `nameProperty: 'code'` on `geo` and use those codes for region configuration names. Build a code-to-label mapping from each feature's `properties.name` to display localized names.

### Implement drill-down

Read the feature code when a region is clicked. Check that the target map exists before loading and registering it. Keep the current map and its parents in a path stack, restoring the parent when going back.

A map may contain only its own outline rather than child boundaries. Use the actual features and coverage metadata to decide whether drill-down is available. The site's navigation index is generated by its build script and is not part of the package API.

Status markers for Chinese administrative areas prefer administrative centers (provincial capitals or seats at province level). When the outline omits coordinates, look them up with `getChinaArea(adcode)`. Fall back to a geometric centroid only when the administrative center is unavailable, then to the outline's bounding-box center if neither is available.

### Loading and lifecycle

Provide loading, error and retry states. When maps or languages change rapidly, use a request sequence or stale flag to prevent an older request from overwriting the latest result. Reload or call `localizeGeoJSON` after changing languages, then register the map again.

Call the chart's `resize()` method when its container changes size. Disconnect observers and call `dispose()` when the component unmounts. Status values and colors in the examples are demo data; provide your own business data.

## Examples on this page

- Asynchronous loading, drill-down, back navigation and status markers.
- Select from `availableMaps` or enter a dynamic ID to check it with `hasGeoJSON`. IDs are case-sensitive; try `us` or an unknown code for an unavailable result.
- Import `china.json` directly and compare its raw bilingual properties with a `localizeGeoJSON` copy. Switching the page language localizes it again without reloading geometry or modifying the source JSON.
- Inspect the bundled manifest’s generation time, fingerprint, map asset count and sources. `availableMaps` also includes the `china` alias, so its length differs from the manifest’s source asset count.

ID checks and JSON localization are independent: this example always uses the directly imported China province JSON for localization. Choosing another ID only changes the availability result. A direct import loads the JSON with the example module; use `loadGeoJSON` when the application needs on-demand loading.
