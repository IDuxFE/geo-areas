# Security policy

The project is in initial development. Security fixes target `main`; older snapshots are not maintained separately.

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/IDuxFE/geo-areas/security/advisories/new). Include the affected commit/version, reproduction steps and impact. Do not disclose secrets or exploitable details in public issues.

Ordinary data errors and feature requests belong in public issues. Third-party source licenses and map coverage limitations are documented in the data package.
