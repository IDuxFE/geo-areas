## 复查

运行 `pnpm audit:data`，使用与 manifest 哈希一致的缓存源进行离线核对；缺缓存或任一不一致时失败。用 `pnpm update:data` 刷新源，再重新核对。本报告证明对所记录源快照的保留情况，不证明上游已覆盖最新行政区划。
